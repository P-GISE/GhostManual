# 운영 배포

갱신일: 2026-10-16. **개발 도구 환경은 구성됨, 제품 실행·배포는 미정**이다.

## 개발 환경과 설정

개발 도구 설치는 Node24·Python3.12·uv·GNU Make·Git을 전제로 한다. 이것은 도구의 요구 조건이며 제품의 기술 선택이 아니다. 설치 명령·버전은 [개발 도구 가이드](개발_도구_가이드.md)와 [versions.mk](../tools/versions.mk)를 따른다.

CodeGraph MCP는 [.codex/config.toml](../.codex/config.toml)에 등록돼 있다. 프로젝트 신뢰와 새 세션 로드가 필요하다. 초기화 후 코드·인덱스는 없으며 새 코드가 생기면 index 명령으로 만든다. .dev-tools 캐시는 Git에 포함하지 않는다.

## 현재 CI

[Iron Laws](../.github/workflows/iron-laws.yml)는 PR 변경 파일과 수동 전체 검사를 제공한다. [Strix](../.github/workflows/strix.yml)는 계정·키·예산·Docker를 준비한 뒤 수동 실행한다. 제품 테스트·빌드·배포 workflow는 제거돼 현재 없다.

확인 시점 초기화 commit d13fe60의 GitHub Iron Laws check는 success였다. 이 결과는 제품 테스트·제품 보안·실 LLM 검증을 뜻하지 않는다. 이후 변경에는 새 검증이 필요하다.

## 제품 실행·배포 절차

미정. 요구사항·기술·제공자·대상 환경을 정한 뒤 실행 명령·변수명·배포·migration·health·모니터링·롤백을 작성한다. 과거 앱의 포트·서버·비밀 설정을 새 기본값으로 가져오지 않는다.

## 운영 자원과 복구

운영 서버·실제 DB·DNS는 저장소 초기화 범위 밖이며 이번 작업에서 변경하지 않았다. 실제 가용성·데이터·비용 상태는 새 운영 작업에서 별도 확인한다.
저장소 초기화 전 파일은 backup/before-reset-2026-10-16에 보존돼 있다. 파일 복구와 실제 서버/DB 복구는 다른 작업이다.

## PC 수집 PoC 전제

사용자가 PC 화면·여러 앱의 작업 흐름 수집을 선택했다. 첫 OS는 Windows로 확인됐다. Windows 버전/장비·화면/앱 정보 수집 권한·로컬 보관·외부 전송·생성 모델·비용 상한·보관/삭제를 실험 전에 결정한다. 설치된 Node/Python 도구 버전으로 데스크톱 제품 프레임워크를 확정하지 않는다. OS 권한 거부·잠금·보호된 화면과 앱 접근 한계는 PoC 시나리오에 포함한다.

## PoC 구현 환경 제안

[구현 설계](superpowers/specs/2026-10-16-windows-local-poc-design.md)는 Windows11 x64 단일 모니터·일반 권한, .NET10/C#·WPF를 첫 후보로 제안한다. 이 환경에서는 dotnet 실행 파일도 아직 확인되지 않았으며 설치·패키지/SDK 호환 확인이 필요하다. Core unit과 Windows 실제 수집은 별개 검증이다. 실제 OS/앱/Office·허용 범위·보관·provider 전송/비용 조건은 실행 전 확정한다.
