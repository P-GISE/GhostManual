## 저장·보관·운영 정책 제안
공개 데모 데이터는 생성 후 7일, 만료 즉시 접근 차단·하루 1회 삭제. 이 정책은 아직 실행되지 않는다.
초기 데모는 방문자 본문 DB 백업을 만들지 않는다. 장애 시 해당 데모 데이터가 유실될 수 있음을 안내하고 합성 seed로 재시연한다.
기업 운영 전에는 보관·삭제와 양립하는 백업/복원 정책이 별도로 필요하다. 그 상태를 이번 MVP 완료와 혼동하지 않는다.
일반 로그는 원문·토큰 없이 7일 보관. health는 DB 연결 가능 여부를 확인하되 API 키·내부 오류를 공개하지 않는다.
모델 장애·검색 실패·DB 실패를 구분하여 기록한다. 현재 monitoring/cleanup timer는 없다.
