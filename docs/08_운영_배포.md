# 운영·배포
변경일: 2026-10-03

## 확인된 상태
로컬 Node 24.20.0·npm 11.19.0을 실행 확인했다. Docker·SSH 실행 파일은 찾았으나 Docker 엔진과 원격 SSH 접속은 검사하지 않았다. python 명령은 Microsoft Store 안내와 함께 실패했다.
Cloudflare pigs0516.com과 AWS 이름의 기존 터널 DNS, Tailscale Linux·Windows 장비, P-GISE GitHub CLI 인증을 앞선 조사에서 확인했다.
2026-10-03 Tailscale SSH 추가 인증 후 서버 읽기 전용 조사 성공: Linux, Docker29.5.3, 메모리1906MB/가용805MB, 디스크13GB 남음, 앱 포트3000·3100 사용. 운영체제와 실행 자원은 확인했지만 EC2 상품 사양·요금 및 GhostManual 추가 부하는 미확인이다.
근거: [배포 구성 검토](배포_구성_검토.md). 목표 URL은 ghostmanual.pigs0516.com이며 아직 생성하지 않았다.

## 실행 명령 상태
현재 package.json·lock file·Dockerfile·compose·migration·seed가 없으므로 실행 가능한 앱 명령은 없다.
구현 계획의 제안 script 이름: dev, build, start, lint, typecheck, test, test:integration, test:e2e, db:migrate, db:seed, data:cleanup.
이 명령들을 실행했다고 기록하지 않는다. 파일 생성 후 정확한 실행법과 전제조건을 이 문서에 추가한다.

## 제안 환경 변수
| 변수 | 용도 | 보안·초기값 |
|---|---|---|
| DATABASE_URL | 전용 PostgreSQL 연결 | 서버 secret, 실제 값 미설정 |
| APP_ORIGIN | Origin·공유 URL 기준 | https://ghostmanual.pigs0516.com |
| OPENAI_API_KEY | OpenAI 인증 | 서버 secret, 미보유 |
| OPENAI_MODEL | 생성·답변 모델 | 초기 후보 gpt-4.1-mini, 실 평가 후 고정 |
| AI_ENABLED | 실 API 호출 허용 | 기본 false |
| AI_DAILY_LIMIT | 전역 시도 횟수 | 제안 100, UTC 일자 |
| IP_HASH_SECRET | 속도 제한용 HMAC | 서버 secret, 구현·배포 때 생성 |
| DEMO_RETENTION_DAYS | 본문·공유·세션 보관 | 제안 7 |

모델 키를 NEXT_PUBLIC_ 변수로 만들지 않는다. 배포 secret은 서버 전용 설정으로 주입하고 .env.example에는 변수명과 비밀이 아닌 설명만 남긴다.
변수 값은 문서나 Git에 쓰지 않는다. provider 결제·예산과 계정은 사용자가 준비해야 하며 현재 미확인이다.

## 제안 배포 절차와 롤백
1. Tailscale 경유 서버 사양·부하·디스크·현재 포트·Docker·터널 상태를 읽기 전용 조사.
2. 구현된 앱의 lint/type/test/build 및 로컬 브라우저 흐름 검증.
3. 전용 Compose 프로젝트·전용 DB·볼륨 준비. 앱은 제안 127.0.0.1:3200, DB 공개 포트 없음. 3100은 EventOps 사용 중이다. 새 앱은 로컬/CI 빌드 후 배포하며 서버 메모리 한도를 부하 검증한다.
4. 명시적 migration 실행, 합성 seed, health 확인. 무조건 시작 시 자동 migration하지 않는다.
5. Cloudflare에 GhostManual 호스트만 연결 후 외부 HTTPS 및 별도 브라우저 흐름 확인.
6. Git commit·이미지 식별자·migration 버전·검증 결과를 ledger에 기록.
7. 롤백은 호환 가능한 이전 앱 이미지로 복귀. 파괴적 down migration은 자동 실행하지 않는다.

기존 AWS가 부족할 경우 신규 서버의 사양·추가 비용 결정이 필요하다. 지금 비용 발생 리소스를 만들지 않았다.
GitHub Actions는 lint·typecheck·테스트·build부터 사용한다. 공개 배포 자동화와 SSH secret 부여는 실제 구성 확인 후 계획에 명시한다.

## 저장·보관·운영 정책 제안
공개 데모 데이터는 생성 후 7일, 만료 즉시 접근 차단·하루 1회 삭제. 이 정책은 아직 실행되지 않는다.
초기 데모는 방문자 본문 DB 백업을 만들지 않는다. 장애 시 해당 데모 데이터가 유실될 수 있음을 안내하고 합성 seed로 재시연한다.
기업 운영 전에는 보관·삭제와 양립하는 백업/복원 정책이 별도로 필요하다. 그 상태를 이번 MVP 완료와 혼동하지 않는다.
일반 로그는 원문·토큰 없이 7일 보관. health는 DB 연결 가능 여부를 확인하되 API 키·내부 오류를 공개하지 않는다.
모델 장애·검색 실패·DB 실패를 구분하여 기록한다. 현재 monitoring/cleanup timer는 없다.

## AI 비용과 개인정보
사용자가 API 계정이 없다고 확인했으며 제공자 선택을 위임했다. OpenAI 초기 후보는 상세 설계 9·13절 참조.
store:false는 외부 제공자의 모든 보관을 없애는 설정이 아니다. 이용자에게 외부 전송과 제공자 정책을 설명한다.
공개 전 운영자 연락처, 실제 보관 정책, API 사용 예산, 합성 데이터 사용 안내를 확정한다. 정책 페이지는 법률 검토 전 초안이다.
