# API 명세 — 작업 계약 초안

HTTP endpoint·전송 방식·인증·서버 유무는 아직 미정이다. PC 수집기와 로컬/원격 처리 사이에서 필요한 논리 작업만 정리한다. 구현된 API가 있다는 뜻은 아니다.

| 논리 작업 | 핵심 입력 | 결과·불변 조건 |
|---|---|---|
| beginSession | 업무 목적·허용 범위·수집 설정 버전 | 세션·권한 상태. 수집 불가면 성공으로 처리하지 않음 |
| appendEvents | 세션·이벤트 ID·sequence·허용된 근거 | 중복 없는 수신 결과·누락 표시 |
| pause/resume/stopSession | 세션·상태 변경 | 유효한 상태 전이, 정지 중 수집 경계 |
| excludeEvidence | 이벤트/화면 식별자·제외 사유 | 생성/열람/내보내기 대상에서 제외, 영향 문서 재검토 |
| requestDraft | 세션·고정 입력 버전 | 생성 시도 상태·초안 버전 또는 실패 |
| saveRevision | 문서·기준 버전·수정·출처 | 새 버전. 다른 편집을 덮어쓰지 않음 |
| reviewRevision | 대상 버전·결정 | 승인/반려. 근거 유효성과 권한 확인 |
| exportManual | 승인 버전·허용 근거 | 결과물. 형식/공유 방식은 PoC 후 결정 |
| deleteSession | 대상·삭제 범위 | 근거·파생본 처리 결과. 실패를 성공으로 표시하지 않음 |

실제 타입·오류 코드·중복/오프라인 동기화·대용량 업로드·접근 제어는 OS·처리 구조·데이터량과 PoC 결과를 바탕으로 확정한다. 원본 인증정보·키를 요청 예시에 넣지 않는다.
