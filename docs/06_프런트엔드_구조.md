# 프런트엔드 구조 — 화면 기획 초안

구현 프레임워크와 검토 화면의 데스크톱/웹 배치는 미정이다. 아래는 PC 수집 PoC에 필요한 논리 화면 제안이다.

| 화면/영역 | 핵심 행동 | 반드시 구분할 상태 |
|---|---|---|
| 업무 기록 준비 | 업무 목표·범위·권한 확인 | 수집 불가·미지원·준비됨 |
| 수집 상태 표시 | 시작·일시정지·재개·종료 | recording·paused·권한 상실·기록 공백 |
| 세션 timeline | 순서·앱 전환·화면 근거 확인, 제외 | 관찰됨·유실·마스크·제외 |
| 매뉴얼 편집 | 단계와 근거 대조·보완·순서 수정 | 자동 관찰·작성자 설명·확인 질문 |
| 검수·내보내기 | 승인/반려·결과물 확인 | 초안·검수 중·승인·재검토 필요 |

수집을 숨기거나 정상 기록하지 못한 상태에서 진행 중으로 표시하지 않는다. 전체 화면을 기본 업로드하는 흐름으로 확정하지 않는다. 실제 PC 권한 화면·트레이/상태 표시·단축키·키보드 접근성과 화면 검증은 OS 선택 후 설계한다.
