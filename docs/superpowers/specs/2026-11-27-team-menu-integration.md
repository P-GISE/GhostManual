# PR117 메뉴 통합 범위와 검증 계획

사용자는 PR118 CI 확인 후 병합, PR117의 최신 기본 기준 전체 검토·통합 검증을 지시했다. PR118은 c34ba518로 병합됐다. PR117 원본63a480c와 작성자 브랜치는 보존하고 자체 fix/team-hub-menu-integration에서 통합한다. 사용자 답변에 따라 박효민의 팀 중심 신규 등록 UI를 채택한다. 기존 개인 자료·양식·공유 접근은 유지하고 자동 이동·자동 승계·API 권한 정책 확대는 하지 않는다.

## 구현 순서

1. 회귀 테스트를 먼저 추가해 격리 CI에서 실패를 확인한다. 공유 서버에서는 빌드·npm·DB·브라우저 검사를 실행하지 않는다.
2. 신규 업무 화면은 문서함 조회 중·실패 시 입력 폼을 표시하지 않고, 개인 세션은 팀 선택 안내를 표시한다. 팀 세션에서만 신규 UI를 연다.
3. 빈 개인 업무 계정도 내 문서함의 기존 개인 양식 링크로 개인 세션을 재검사하고 목록·편집·삭제에 접근한다. 개인 양식 목록에 신규 업로드 UI를 두지 않는다. 기존 API 호환은 유지한다.
4. 팀 생성 초안은 검색/필터 재조회로 제거하지 않는다. 중복 요청·이탈 후 세션 변경/강제 이동을 막고 생성 id를 받은 후 실패하면 세션 전환만 재시도한다. 생성 결과가 불명확하면 목록 재조회로 확인한다.
5. 성공한 개요 조회는 과거401 안내를 지운다. 긴 팀 breadcrumb·관리자 메뉴·키보드·3viewport 넘침 검사를 보강한다.
6. #118 가입 helper의 기본팀 생성 및 초대 도착 경로 변경을 대조한다. 인증 기본 경로/library와 공유 fragment 보존도 검토한다.

## 금지 범위와 완료 조건

PR117/통합PR 병합, 운영 배포·환경·이미지 정리·migration014·backfill·대표 지정은 이번 범위 밖이다. 전역 SQL 권한·AI/메일 전송 범위는 바꾸지 않는다. 격리CI의 lint/type/unit/DB/build/E2E/session/cookie/a11y와 실제 캡처를 대조한다. 실행하지 못한 항목과 자동 승인 차단은 완료로 표시하지 않는다.
