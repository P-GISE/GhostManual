# 운영 공간·보관 정책 후속 작업 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 운영·롤백·개인정보를 보존하면서 다음 배포에 필요한 공간을 확보하고 박기성 운영·보고서 후속을 완료한다.

**Architecture:** 배포 채팅과 단일 서버 writer를 유지한다. 읽기 전용 이미지·참조 목록을 작성하고 현재/직전 정상/활성 배포 영수증 이미지는 보존한다. 과거 수동 롤백 이미지는 소유자 승인 없이 폐기하지 않는다. 보관 제안과 실제 설정을 분리한다.

**Tech Stack:** Docker, 기존 deploy.lock, Python 표준 라이브러리, PostgreSQL 18, systemd, AWS S3.

**Spec:** 사용자 지시(박기성 남은 작업 진행), [현재 작업 목록](../../99_해야할일.md), [실제 운영 경계](../../운영_DB권한_외부백업_2026-11-02.md).

## Global Constraints

- 로컬 PC 변경 없음. 원격 전용 브랜치에서 준비한다.
- 서비스·DB·볼륨·백업·환경 파일·다른 프로젝트 이미지를 삭제하지 않는다.
- 전역 prune·force 제거·기존 역할 SQL 재실행 금지.
- EBS 중단·새 유료 자원은 시간/비용 조건과 최종 승인 전 실행하지 않는다.

## Review Focus

- 중지된 컨테이너도 이미지를 참조하면 후보에서 제외한다.
- 과거 문서의 이미지 언급과 실제 실행·직전 정상·활성 영수증 참조를 구분한다.
- 승인 후 상태가 바뀌면 잠금 안에서 재검사하고 삭제 전에 중단한다.
- 이미지 삭제로 되돌리기 능력이 줄어드는 버전은 명시한다. DB 백업 보존과 혼동하지 않는다.
