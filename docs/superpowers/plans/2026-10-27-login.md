# 로그인·링크 공유 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이메일(인증 필수)·구글 로그인을 붙이고, 로그인한 사용자만 자기 문서함을 쓰며, 매뉴얼은 Colab처럼 비공개 기본·링크 공유를 켜고 끌 수 있게 한다.

**Architecture:** 기존 workspace·session·share 모델을 그대로 두고 그 위에 계정을 얹는다. 사용자마다 만료 없는(`expires_at='infinity'`) workspace 하나를 두고, 로그인하면 그 workspace의 `owner` 세션(기존 `gm_owner` 쿠키)을 발급한다. 그래서 자료·매뉴얼·질문 API와 `assertSession`은 거의 바뀌지 않는다. 공유는 기존 `shares`·`reader` 세션을 재사용하되, 토큰 교환에 로그인을 요구하고 링크를 다시 복사할 수 있게 토큰을 함께 저장한다.

**Tech Stack:** Next.js 16 App Router, PostgreSQL 18(pg), Zod 4, Node `crypto.scrypt`, `nodemailer`(Gmail SMTP), Vitest·Playwright.

**Spec:** `docs/superpowers/specs/2026-10-23-landing-login-design.md`

## Global Constraints

- 로그인 필수. 익명 workspace 생성 API(`POST /api/workspaces`)는 제거한다. 기존 익명 workspace 행은 기존 7일 정리로 사라지게 둔다.
- 이메일 인증 필수: 인증 전 계정은 로그인 세션을 받지 못한다. 인증 링크 24시간, 한 번만 사용.
- 비밀번호 8~128자, `scrypt`(사용자별 16바이트 salt) 해시만 저장, `timingSafeEqual`로 비교.
- 비밀번호·인증 토큰·세션 토큰·OAuth verifier는 DB·로그에 평문으로 남기지 않는다. 예외: 공유 링크 토큰은 재복사를 위해 저장한다(로그인한 사람만 쓸 수 있음).
- 로그인 실패 문구는 하나: "이메일 또는 비밀번호가 올바르지 않습니다."
- 세션 30일. 쿠키 `HttpOnly; SameSite=Lax; Path=/`, https에서 `Secure`(기존 `sessionCookie`).
- 변경 요청은 기존 `endpoint`의 `Origin` 검사를 그대로 받는다. 구글 콜백(GET)은 `state` 검사로 보호한다.
- 시도 횟수 제한: 기존 `limitRequest`에 종류 추가. 시간당 IP별 `login` 20, `signup` 10, `resend` 5.
- 이름 1~40자, 이메일은 소문자·앞뒤 공백 제거 후 저장, 254자 이하.
- 비밀 값은 `.env`에만: `SMTP_USER`, `SMTP_APP_PASSWORD`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`. 테스트는 `MAIL_DRIVER=file`, `MAIL_DIR`로 실제 메일을 보내지 않는다.
- 커밋 작성자는 박효민, AI 기여 표기 없음.

## Review Focus

- 같은 이메일로 두 번 가입(대소문자만 다름) → 두 번째는 "이미 가입된 이메일"이 아니라 같은 안내("인증 메일을 보냈습니다")로 끝나 계정 존재 여부가 드러나지 않아야 한다. 미인증 계정이면 인증 메일만 다시 간다. (Task 3)
- 인증 링크를 두 번 누름 → 두 번째는 "이미 사용된 링크"로 거부되고 로그인 화면 안내. (Task 3)
- 링크 공유를 끈 뒤, 이미 열어 둔 후임자 화면에서 새로고침 → 401과 "공유가 취소됐습니다". (Task 6)
- 로그인 안 한 사람이 공유 링크를 열고 로그인 → 원래 공유 문서로 돌아온다(토큰이 `#` 뒤에 있으므로 로그인 화면으로 넘길 때 `next`에 보존). (Task 6)
- 구글 이메일이 미인증 비밀번호 계정과 같음 → 구글 계정이 그 계정을 넘겨받고 기존 비밀번호는 지워진다. (Task 7)
