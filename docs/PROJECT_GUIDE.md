## 새 요구사항

GhostManual 재설계 방향은 확인됐다. 세부 요구사항은 사용자가 추가할 예정이며 다음을 확인한 뒤 01·02를 구체화한다.

1. 누구의 어떤 문제를 해결할지와 성공 기준
2. 핵심 사용자 흐름과 반드시 필요한 기능
3. 입력 데이터·결과·민감정보·권한
4. MVP 범위·제외 기능·일정·비용 제약
5. 사용할 서비스·기술·배포 환경에 대한 요구 또는 선택 위임

재설계 대상은 GhostManual이다. 이전 기능·화면·데이터 모델을 그대로 복원한다는 뜻은 아니다. 제품 기술 스택·모델·계정·배포 계획은 새 요구사항에 따라 결정한다.
