# 프로젝트 맥락

갱신일: 2026-10-16. 현재 단계는 **GhostManual 재기획·PC 수집 PoC/개념 설계 초안 검토**이다.

## 사용자 결정

- AGENTS와 00~10·99 문서 전체를 “프로젝트 가이드”라고 부른다.
- 상세 가이드는 docs 폴더에 모으고 루트 AGENTS는 문서 진입점만 둔다.
- 개발 도구와 빈 제품 설계 가이드를 유지하고 기존 앱·테스트·DB·배포 설정·작업 기록을 제거한다.
- 이전 제품 범위·기술 선택·승인·검증 결과를 새 프로젝트에 자동 승계하지 않는다.
- 사용자 선택: “GhostManual을 처음부터 다시 설계 — 요구사항 추가 예정”.
- 핵심 목적: 업무 수행 과정을 자동 수집해 인수인계 매뉴얼을 만드는 서비스.
- 첫 PoC 수집 범위: PC 전체 업무의 화면·여러 앱 작업 흐름. 첫 지원 OS는 추가 확인 중.

## 확인된 방향과 제안 문서

확인: PC의 업무 수행 과정을 자동 수집해 인수인계 매뉴얼 작성. 처음부터 기획·PoC·ERD로 재설계.

- [제품 기획서 초안](기획/01_제품_기획서.md): 문제·사용자·가치·범위·기능 인수 조건
- [PoC 검증 계획 초안](기획/02_PoC_검증_계획.md): PC 수집 경로 비교·문서 품질·인수인계 재현·판단 기준
- [개념 ERD](03_데이터베이스_설계.md): 세션·이벤트·화면 근거·생성·문서 버전·검수

01~07은 이 목적에 맞는 제안 초안이다. 사람 검수·수집 제어·근거 연결·최소 PoC 범위와 수치 목표는 제안이며 아직 확정 요구사항이 아니다. 수집 OS·대표 업무·보관·모델·예산·일정·실 사용자 환경은 미정이다. 예전 기능·기술·데이터 모델을 복구한 것이 아니다.
