## 새 요구사항

아직 제공되지 않았다. 다음을 확인한 뒤 01·02를 작성한다.

1. 누구의 어떤 문제를 해결할지와 성공 기준
2. 핵심 사용자 흐름과 반드시 필요한 기능
3. 입력 데이터·결과·민감정보·권한
4. MVP 범위·제외 기능·일정·비용 제약
5. 사용할 서비스·기술·배포 환경에 대한 요구 또는 선택 위임

저장소 이름이 GhostManual이라는 사실만으로 이전 제품을 다시 만든다고 확정하지 않는다. 제품 기술 스택·모델·계정·배포 계획도 미정이다.
