# 프로젝트 맥락

갱신일: 2026-10-16. 현재 단계는 **Windows 로컬 PoC 구현 설계·작업 계획 검토**이다.

## 사용자 결정

- AGENTS와 00~10·99 문서 전체를 “프로젝트 가이드”라고 부른다.
- 상세 가이드는 docs 폴더에 모으고 루트 AGENTS는 문서 진입점만 둔다.
- 개발 도구와 빈 제품 설계 가이드를 유지하고 기존 앱·테스트·DB·배포 설정·작업 기록을 제거한다.
- 이전 제품 범위·기술 선택·승인·검증 결과를 새 프로젝트에 자동 승계하지 않는다.
- 사용자 선택: “GhostManual을 처음부터 다시 설계 — 요구사항 추가 예정”.
- 핵심 목적: 업무 수행 과정을 자동 수집해 인수인계 매뉴얼을 만드는 서비스.
- 첫 PoC 수집 범위: PC 전체 업무의 화면·여러 앱 작업 흐름. 첫 지원 OS는 Windows로 사용자 확인.
- 첫 대표 업무는 최신 응답인 웹 자료 조회 → Excel 정리 → 결과 문서 작성으로 반영한다. 앞서 응답한 파일 탐색기·문서·메일 업무는 확장 후보로 구분한다.

## 구현 제안의 상태

C#/.NET10·WPF와 Windows11 x64 단일 모니터, 로컬 전용 저장, raw 이미지 후보 메모리 전용, template baseline/provider opt-in을 권고안으로 작성했다. 사용자 확정 기술 선택이 아니며 SDK 설치·Windows 빌드·수집 실험·제품 코드는 아직 없다. 순수 Core를 이 환경에서 검증하더라도 Windows 화면 수집·인수인계 가치 검증을 대체하지 않는다.
