복귀한 앱의 이미지·원본 설정·권한·네트워크·포트·건강 상태를 수동 검증하고, 독립 검토를 거쳐 실제로 달라진 컨테이너 ID 한 필드만 영수증과 정합화했다. 이전 영수증과 실패 표식 원본은 root 전용 증거로 보존했다. 동일 CI/정확한 artifact를 다시 확인한 한 차례 재시도(attempt 4)가 성공했다. 설치 모듈·보호 검사·권한 정책을 완화하지 않았다. Docker DNS 설정의 `null`/빈 배열 표현 차이가 원인일 가능성은 있으나, 최초 컨테이너의 전체 HostConfig가 없어 원인은 확정하지 않는다.

서버 root 전용 실행 증거는 운영 작업 디렉터리에 보존한다. 원문 환경 파일·토큰·실제 업무 자료·수신 주소는 이 문서와 Git에 복사하지 않는다.
