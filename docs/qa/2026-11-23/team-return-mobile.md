## 수정 계약

모바일 선택기를 기존 메뉴 칸 폭 안으로 제한하면서44px·키보드 접근을 유지한다. 선택 팀 삭제·본인 나가기 성공 시 기존 팀 세션은 폐기하고 새 개인 세션을 발급한다. 권한·이름·마지막 관리자 거절에서는 원래 세션을 보존한다. 다른 팀 삭제와 다른 사람 내보내기는 호출자 세션을 바꾸지 않는다. 팀 자료 삭제·이력 보존 규칙은 기존 정책을 따른다. 새 migration은 없다.

최종 구현·GREEN·병합·운영 반영 여부는 이 수정 PR의 최신 실행 기록과 프로젝트 가이드 운영 버전을 구분해 확인한다. #101 앱·워커 완료가 이 수정의 운영 배포를 뜻하지 않는다.

## 구현 경계

`newAccountSession`은 기존 전환의 세션 발급 SQL을 공유한다. `lockExitHome`은 현재 선택 팀 종료 시 개인·팀 workspace를 UUID 순으로 먼저 잠그고 기존 계정·세션·역할 검사를 거친다. 삭제·본인 나가기와 개인 세션 발급은 같은 트랜잭션이며 발급 실패도 전체 롤백 대상이다. 두 DELETE handler는 새 세션이 있을 때만 기존 HttpOnly·SameSite·HTTPS Secure 쿠키 규칙을 사용하고 화면은 성공 뒤 팀 목록을 다시 연다.

CSS는 `max-width: min(180px, 100%)` 한 줄로 메뉴 칸을 넘지 않도록 제한한다. 기존44px 조작 크기·포커스·데스크톱180px 상한을 유지한다.
