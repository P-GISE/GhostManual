## 검증 한계

Aside는 route/unroute를 제공하지 않아 지연·503 모의는 CI에서 검증했다. 네이티브 dialog 이벤트가 관측되지 않아 실제 취소 버튼 동작은 판정 보류다. 임시 confirm=false 검증은 앱의 거부 시 차단 동작을 확인한 것으로 네이티브 대화상자 검증과 구분한다. 스크린샷은 CDP timeout2회로 저장하지 못했고 DOM·저장값을 근거로 사용했다.

최대 부하와 Strix 실전 스캔은 이 배포 검증에 포함하지 않았다. Strix는 설치와 인증·모델 설정·실행을 구분하며 후자는 미완료다. OOXML 동기 전체 파싱의 자원 측정은 후속이다. 운영 서버 자체 빌드·무단 이미지 추가 삭제·AI 호출·실제 이메일 발송은 하지 않았다.
