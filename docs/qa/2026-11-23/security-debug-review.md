## 추가 검토에서 발견한 문제와 수정

- 취소된 초대: 초대 수락이 팀 잠금을 기다리는 동안 취소돼도 이전 조회로 가입하던 경합을 잠금 이후 재조회로 차단한다.
- 폐기 세션: 팀 작업과 공유 세션 발급에서 문서함을 정렬해 잠근 뒤 계정·세션을 재검증하고 폐기와 직렬화한다.
- 이전 비밀번호: 비밀번호 검증을 마친 로그인 요청이 재설정 이후 세션을 만들지 못하도록 현재 해시를 잠금 아래 다시 확인한다.
- 편집 유실: 매뉴얼·자료·양식은 저장 대기 중 편집 조작을 잠그고, 양식에는 기존 미저장 이탈 경고를 적용한다. 문서함 전환 실패를 화면에 표시한다.
- 검사 한도 회귀: 유효하지 않은 경로 때문에 항상 실패하던 외부 추출 블록 한도 테스트를 유효한 5,000개 성공·5,001개 실패로 보완한다.

이 변경은 기존 migration을 수정하거나 새로운 migration을 추가하지 않는다. 새 수정은 103db6f 운영 앱·큐 워커에 반영했다. 명시적 잠금·비밀번호 검증 gate를 사용하는 DB 회귀 4건과 저장 응답 지연·전환 실패 브라우저 회귀 4건을 추가했다. 코드 검토는 실행 검증과 구분한다. CI 결과는 PR의 최신 커밋을 기준으로 확인한다.
