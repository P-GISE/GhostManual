## 수정 및 검증

- 배열 수식의 후속 칸은 기존 snapshot에서 수식 출처가 사라져 일반 문자열과 구분되지 않는다. 따라서 첫 행을 포함한 모든 셀 값을 AI 입력·검색 근거에서 제외한다. 제목·시트 이름/크기·변경 수식·질문/답변의 전송은 유지하고 안내를 일치시킨다. 머리글 값에 의존한 검색/AI 문맥은 줄어드는 대신 불확실한 데이터를 보내지 않는다.
- 기존 immutable source_revisions.text를 덮어쓰지 않고 파일 검색 근거를 저장된 스냅샷에서 안전하게 재구성한다. 이미 발생한 외부 전송을 취소하거나 기존 작성 답변/매뉴얼을 일괄 삭제하지 않는다.
- AI 초안 입력은 요청한 revision에 고정하고 입력 구성 전 버전 충돌을 거부한다. 네트워크 호출 뒤 변경된 자료의 저장은 기존 optimistic lock으로 거부한다.
- Reader의 칸별 이전 값 API와 화면을 차단한다.
- 지연된 유사 자료 검색 결과가 바뀐 파일에 적용되는 문제, 칸 변경 조회 재시도 상태를 수정한다.
- 비용: Sonnet 캐시 읽기 $0.10/백만 토큰, Haiku 총 입력100,000초과 요율을 반영한다. [공식 단가](https://platform.claude.com/docs/en/about-claude/pricing), 확인일2026-11-02. 현재 지원하는 기본 요청 기준 추정이며 실제 청구액·다른 캐시 TTL/지역·속도 옵션을 보증하지 않는다.

원격 독립 QA DB의 수정 전 회귀5건 실패/11통과→수정 후16/16통과. 비용 회귀2건 실패→5/5통과. 첫 수정에서 원격 전체 단위132개·DB 통합129개를 확인했다. 추가 독립 검토가 실제 XLSX 배열수식 캐시를 발견해 기존 gate는 REJECT했다. 실제 ZIP/XLSX 파서를 거치는 배열 캐시·기존 검색 근거 회귀2건을 RED로 확인한 뒤 첫 행 값을 전면 제외하는 보완 후 관련11개를 통과했다. 브라우저 수정 전 CI41412923718은 새 경계 사례에서6실패·기존64통과를 확인했다. 수정 후 화면 CI와 최종 전체 검사 결과는 통합 PR 최종 기록을 따른다. 실제 사용자 데이터나 키로 회귀 테스트하지 않는다.

## 운영 읽기 전용 감사

운영 파일 revision2개·snapshot2개, 비문자/수식 첫 행 보유revision1개, 그 값과 과거 검색 텍스트가 문자열 일치하는 영향후보1개를 집계했다. 외부 전송 사실을 증명하는 수치는 아니다. 원문·이름·키는 출력하지 않았다.

앱은 node 사용자·127.0.0.1:3200, DB 공개 포트없음. .env/compose root0600·배포상태폴더0700, 같은서버의 root0600 DB dump와 격리복원 이력이 있다. 정기/외부 백업 완료 근거는 확보하지 못했다. DB 앱 역할에 superuser/createdb/createrole 권한이 있어 migration역할과의 분리가 후속 과제다.

게스트 ext4와 블록 장치를 확인했으나 AWS EBS 저장 암호화는 게스트만으로 판정할 수 없다. AWS 인증된 볼륨 정보·KMS 상태 확인이 필요하며 AWS 인증을 임의 설정하지 않았다. 디스크 미암호화로 단정하지 않는다. 암호화/권한/데이터 보존 변경은 실행하지 않았다.
