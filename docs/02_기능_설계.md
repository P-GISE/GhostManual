# 기능 설계 — 기획 초안

기능 F-01~07의 기준은 [제품 기획서 7절](기획/01_제품_기획서.md)이다. 아래는 PC 업무 수집 목적에 맞춘 제안이며 첫 OS는 Windows이며 상세 수집 방식·권한은 대표 업무와 실제 장비에서 검증한다.

| 영역 | 입력/사용자 행동 | 결과 | 실패·확인 조건 |
|---|---|---|---|
| 기록 준비·시작 | 업무 목표·허용 앱/영역·기록 시작 | 수집 상태가 보이는 세션 | 권한 거부·지원 불가를 정상 기록으로 표시하지 않음 |
| PC 업무 수집 | 앱 전환·지원 행동·화면 변화 | 순서·근거·공백이 있는 timeline | 정지/범위 밖 제외, 재전송 중복과 유실 구분 |
| 기록 검토 | 세션 종료·이벤트/화면 확인·제외 | 생성 가능한 입력 집합 | 제외 근거가 모델 입력·내보내기에 섞이지 않음 |
| 초안 작성 | 고정된 허용 입력 | 목적·절차·완료 기준·근거·확인 질문 | 장애·관찰 불가·모델 추측을 구분 |
| 보완·검수 | 단계 수정·작성자 설명·검수 결정 | 새 버전·승인 또는 반려 | 관찰 근거와 사람 보완의 출처 보존 |
| 활용 검증 | 검수본으로 다른 사람이 업무 수행 | 재현 성공·실패와 도움 요청 기록 | 세션 저장 성공만으로 가치 검증 완료 처리하지 않음 |

데이터 삭제·검수 후 근거 변경·내보내기 범위는 상세 설계에서 함께 정한다. 자동 업무 실행·상시 감시·모든 앱 지원·질의응답을 현재 확정 기능으로 추가하지 않는다.

## 첫 대표 업무

사용자의 최신 선택은 웹 자료 조회 → Excel 정리 → 결과 문서 작성이다. 구체적인 합성 과제·정답 절차·실패 변형은 [Windows 시나리오 S-01](기획/03_Windows_대표업무_시나리오.md)에 둔다. 구매 요청이라는 업무 소재와 앱 조합은 평가용 제안이다.
