# 기능 설계
변경일: 2026-10-03
상태: 아래 기능은 모두 미구현이다. 사용자 요구를 실행 가능한 인수 조건으로 정리한 제안이며 실행 결과가 아니다.
공통: Owner는 해당 데모 소유자 세션, Reader는 검수 매뉴얼 공유 독자다. 브라우저의 ID만으로 권한을 판정하지 않는다.

| 기능·목적 | 사용자·입력 | 처리·출력 | AI | 예외·fallback | 완료·테스트 조건 |
|---|---|---|---|---|---|
| 자료 등록: 경험 기록 | Owner, 제목·직접 본문 또는 UTF-8 TXT/MD | 서버 검증 후 SourceRevision 저장 | 없음 | 빈/과대/디코딩 실패는 저장 전 거부, 입력 보존 | A1: 재접속 보존·잘못된 입력 차단 |
| 매뉴얼 생성: 업무 구조화 | Owner, sourceId·revision | 근거 문단이 있는 구조화 초안과 확인 질문 | 있음 | 키 없음/timeout/형식 실패는 원문 유지, 명시적 재시도 | A2: 실 AI 초안·인용 유효성 |
| 초안 수정: 사람 경험 보완 | Owner, 필드·expectedRevision | draft 갱신, 수정 필드 담당자 입력 표시 | 없음 | 동시 수정 409, 편집 내용 보존 | A3·A7: 덮어쓰기 방지 |
| 검수 완료 저장: 지식 확정 | Owner, draft revision·확인 체크 | 불변 ManualVersion 생성, 게시 포인터 교체 | 없음 | 필수 필드 누락·원본 변경 시 게시 거부 | A3: 초안 제외·게시본만 검색 |
| 목록·상세·근거 열람 | Owner 또는 해당 Reader | 원문·매뉴얼·버전 표시 | 없음 | 접근 불가 404, 오래된 근거 라벨 | A4·A5: 다른 공간 접근 차단 |
| 업무 질문: 필요한 절차 안내 | Owner 또는 Reader, 질문 ≤1,000자 | 권한 필터 검색 → 근거 평가 → 답변·출처 | 있음 | 없음/부분/장애 구분, 검색 결과 fallback | A6·A8·A13 |
| 원본 갱신: 지식 최신화 | Owner, 수정 본문·revision | 새 SourceRevision, 연결 Manual 재검토 필요 | 없음 | 생성·답변 중 변경은 409 | A7: 과거 답변 버전 유지 |
| 공유: 후임자 활용 | Owner, 검수 Manual | 만료·취소 가능한 읽기/질문 링크 | 없음 | 초안·재검토 상태 공유 불가 | A4·A5·A9: 별도 브라우저 검증 |
| 데이터 삭제·만료 | Owner 삭제 또는 7일 만료 | 원본·매뉴얼·공유·관련 답변 삭제 | 없음 | DB 실패 시 삭제 성공 표시 금지 | A9: 공유까지 접근 불가 |
| 합성 예시 불러오기 | Owner, 명시적 예시 선택 | 복제된 샘플 자료 또는 사전 작성 예시 | 없음 | 사전 작성임을 표시, 실 AI 결과로 위장 금지 | seed 공간 간 격리 |
| 이용약관·개인정보 안내 | 모든 방문자 | 데모 범위·보관·외부 AI 처리 설명 | 없음 | 운영자 정보 미확정은 공개 전 해소 | A12: 실제 배포 설정과 문구 일치 |

## 매뉴얼 필드
업무명, 목적, 시작 조건, 수행 주기, 담당 역할, 필요 자료·시스템, 순서, 주의사항, 예외·대응, 완료 조건, 원본 근거.
미확인 선택 필드는 null/빈 배열과 확인 질문으로 남긴다. 검수 시 유지 여부를 사람이 확인한다.
검수 완료 필수값: 제목·목적·1단계 이상 절차·완료 조건. 원문에 없던 추가 경험은 담당자 입력으로 구분한다.

## 답변 계약
answer와 procedure의 주장마다 evidenceIds가 있어야 한다. evidence는 서버가 만든 후보 ID·원문·위치·버전으로 구성한다.
confidence는 supported/partial/insufficient, 오류 status는 unavailable로 별도 구분한다. 확률이나 정답 보장을 뜻하지 않는다.
완료 판정은 [설계안 12절 A1~A13](superpowers/specs/2026-10-03-ghostmanual-mvp-design.md)의 실제 실행 결과를 따른다.
