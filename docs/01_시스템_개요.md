# 시스템 개요 — 재기획 초안

확인된 목적: **PC의 화면과 여러 앱에서 수행한 업무 흐름을 자동 수집해 인수인계 매뉴얼을 만드는 서비스**.

상태: 기획·PoC·개념 ERD 작성 중이며 제품 코드는 없다. 첫 지원 OS·대표 업무·화면 수집 세부 방식은 확인 중이다.

## 목적과 사용자

업무 수행자의 사후 문서화 부담을 줄이고, 인수인계 받는 사람이 실제 절차를 재현하도록 돕는다. 수행자·검토자·후임자는 역할 제안이며 기업 계정/조직 체계는 미정이다.

## 제품 범위의 기준

상세 기획의 기준은 [제품 기획서 초안](기획/01_제품_기획서.md)이다. 확정: 자동 수집형·PC 화면/여러 앱·처음부터 재설계. 제안: 명시적 세션, 근거 연결 초안, 사람 검수, 인수인계 재현 검증. 미정: OS·업무·보관·모델·예산·상세 MVP.

## 논리 구성 제안

PC 수집기 → 로컬 제외/마스크·수집 내용 확인 → 허용한 근거와 순서 → 초안 생성 → 사람 보완·검수 → 매뉴얼 활용/내보내기.

화면 수집과 외부 모델 전송은 다른 경계다. 로컬 처리·서버 처리·저장 위치·프레임워크를 위 흐름만으로 확정하지 않는다.

## 검증 우선순위

[PoC 계획](기획/02_PoC_검증_계획.md)에서 수집 적합성 → 문서 품질 → 후임자의 재현성과 문서화 시간 절감을 검증한다. 실제 결과 전에는 구현 완료·타당성 입증으로 표시하지 않는다.
