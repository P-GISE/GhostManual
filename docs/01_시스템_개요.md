## 확인된 제품 정의
GhostManual은 직원 개인에게 의존하던 업무 경험을 AI가 구조화된 매뉴얼로 정리하고, 사람이 검수한 지식을 후임자가 근거와 함께 질문·활용하는 조직 지식 인수인계 플랫폼이다.
근거: [사용자 제품 정의 원문](requirements/제품_정의_프롬프트.md), 특히 3·5·16·31·35절.
사용자는 업무를 남기는 Knowledge Owner와 업무 방법을 찾는 Knowledge Consumer다. HR은 적용 사례 중 하나이며 제품 범위를 한정하지 않는다.
핵심 문제는 개인에게만 남은 업무 맥락, 문서 작성 부담, 필요한 절차를 찾기 어려움, 근거 없는 AI 답변이다.

## 제안 MVP
직접 입력/텍스트 파일 → Source 보존 → 구조화된 Manual 초안 → 사람의 수정·검수 완료 → 저장 → 다른 브라우저에서 공유 Manual 질문 → 관련 Manual·Source 검색 → Answer와 출처 확인.
Source·Manual·Answer의 출처와 버전을 연결하고, 질문에 필요한 지식이 없으면 부족 상태를 표시한다.
원본 변경 후 검수 전 매뉴얼은 신규 답변에서 제외한다. 과거 답변은 당시 버전으로 남긴다.
대표 시연은 합성 '신입 구성원 업무 계정 발급' 업무다. 실제 내부 계정이나 개인정보를 사용하지 않는다.

## 범위 밖
PDF/Word/Excel 파싱, OCR·음성, 기업 계정·조직 권한 관리, 결제, 대시보드, 외부 문서 시스템 전체 연동, 대규모 Multi-Agent, 별도 벡터 DB는 후순위다.
공개 데모의 소유자 세션과 공유 독자 권한은 필수다. 이는 기업용 다중 조직 관리와는 범위가 다르다.

## 기술과 구조
| 항목 | 확인됨 | 제안 |
|---|---|---|
| 로컬 런타임 | Node 24.20.0, npm 11.19.0 | Node 기반 개발 |
| 프런트/서버 | 없음 | Next.js App Router·React·TypeScript |
| 저장소 | 없음 | PostgreSQL + pg, SQL migration |
| 검증 | 테스트·빌드 설정 없음 | Zod, Vitest, Playwright |
| AI | API 계정 없음 | OpenAI Responses API, gpt-4.1-mini 초기 후보 |
| 배포 | 기존 Cloudflare 도메인·터널, Tailscale 장비 목록 확인 | AWS 별도 Compose 프로젝트 |
| 소스 관리 | P-GISE CLI 인증 확인, 로컬 .git 없음 | private P-GISE/ghostmanual |

구조는 브라우저 → Cloudflare → AWS 단일 앱 → 전용 DB 및 OpenAI다. 운영 접속은 Tailscale을 이용한다.
AI에는 매뉴얼 생성 시 입력 자료, 질문 시 권한 내 검색 근거만 전달한다. 외부 웹 검색·Agent 도구는 사용하지 않는다.
제품 MCP는 현재 불필요하다. 이번 조사에 사용한 개발 도구의 MCP와 제품의 기능을 혼동하지 않는다.
