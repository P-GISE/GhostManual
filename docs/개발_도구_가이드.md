# 개발 도구 가이드

제품 코드와 독립된 개발 도구 설정이다. 앱의 기술 스택·계정·모델·배포는 새 요구사항을 정한 뒤 결정한다. 과거 제품의 실행·검증 기록은 초기화했다.

## 설치

Linux/macOS/WSL, Node 24, Python 3.12, uv, GNU Make, Git을 사용한다. 직접 버전과 plugin ref는 [versions.mk](../tools/versions.mk)에 고정한다. 하위 의존성은 upstream 관리이며 전체 dependency lock을 보장하지 않는다.

```bash
make -f tools/Makefile help
make -f tools/Makefile install-core      # CodeGraph·Iron Laws
make -f tools/Makefile install-optional  # OmniRoute·Strix·Headroom
make -f tools/Makefile doctor
```

CLI는 `.dev-tools/`에 격리한다. 기존 클라우드 설치가 사용자 PC에 자동 복제되지는 않는다. npm이 lifecycle scripts 허용을 요구하면 upstream README와 설치 메시지를 확인한다.

## Codex·CodeGraph

`plugins`와 `lazycodex`는 사용자 Codex 설정에 설치해 다른 프로젝트에도 보인다. Superpowers와 LazyCodex를 같은 작업의 오케스트레이션으로 중복 적용하지 않는다. 설치 후 새 채팅에서 사용하고 Ponytail lifecycle hooks는 사용자가 내용을 확인해 신뢰한다. sandbox·승인 정책·모델을 자동 변경하지 않는다.

[Codex 설정](../.codex/config.toml)은 CodeGraph stdio MCP를 등록한다. 프로젝트 신뢰와 실행 PATH의 npx가 필요하고 최초 실행은 registry 접속이 필요하다. 초기화 때 이전 제품의 `.codegraph/`를 제거했다. 코드가 생긴 뒤 인덱스를 새로 만들고, 인덱스가 없는데 기존 제품 심볼을 조회하지 않는다.

## 보안 검사

[Iron Laws 설정](../.iron-laws.yml)은 생성물·캐시를 제외한다. check/audit의 종료0은 기준 통과, 1은 기준 미달, 2는 실행·입력 오류다. 보고서는 `.dev-tools/reports/`에 생성된다. 발견을 숨기기 위해 일괄 suppression을 만들지 않는다.

[Iron Laws workflow](../.github/workflows/iron-laws.yml)는 PR 변경 파일을, 수동 실행은 전체 저장소를 검사한다. 변경된 줄만 검사하는 것은 아니다. 검사 대상이 없는 범위에서는 upstream이 종료2를 반환할 수 있다. 제품 코드가 없으므로 정적 검사 결과만으로 제품 보안을 검증했다고 말하지 않는다.

[Strix workflow](../.github/workflows/strix.yml)는 수동 실행이다. 제품 코드·Docker·제공자 계정·키·예산을 준비한 뒤 사용한다. repository secrets는 STRIX_LLM·LLM_API_KEY, 필요 시 LLM_API_BASE다. 실제 값을 문서에 쓰지 않는다. PR에서 자동 유료 검사를 실행하지 않는다.

로컬 Strix는 `git archive HEAD`의 마지막 커밋 스냅샷을 검사해 미커밋 변경·로컬 .env·캐시를 제외한다. `.dev-tools/strix-source.*`와 `strix_runs/`에 산출물을 남긴다. CI 상세 결과는 artifact로 보관하지 않아 runner 종료 시 소실된다. 실제 비용 한도는 제공자에서 설정한다.

## 선택 서비스

OmniRoute는 127.0.0.1:20128, Headroom은 127.0.0.1:8787에 foreground로 실행한다. 종료는 Ctrl+C다. 계정은 사용자가 연결하고 정상 요청·품질·비용을 별도로 평가한다.

OmniRoute의 DATA_DIR은 `.dev-tools/gateway-data`다. 별도 작업 폴더에서 실행하고 설치 패키지 .env는 건너뛴다. upstream이 기존 사용자 기본 환경 파일을 참조할 수 있으므로 `~/.omniroute/.env`가 있으면 우선순위를 확인한다. 무료 한도는 각 제공자의 자격·약관·잔여량에 따른다.

Headroom은 telemetry를 끄고 stateless·구조적 압축으로 실행한다. `headroom wrap codex`처럼 사용자 설정을 수정하는 명령은 자동 실행하지 않는다. 별도로 사용했다면 upstream의 unwrap 절차로 복구한다. 두 프록시의 압축을 중복 활성화하지 말고 먼저 한 경로부터 평가한다.

## 제외와 제거

도구 캐시·인덱스·보고서·자격증명은 Git에 넣지 않는다. 필요한 산출물을 보존한 후 해당 로컬 도구 디렉터리만 제거한다. plugin은 `codex plugin remove`로 개별 제거하며 기존 사용자 설치를 무작정 지우지 않는다. 운영 서버의 서비스·DB는 이 도구 설정이나 저장소 초기화와 별도다.

## 서버 운영 클라이언트 — 2026-10-17

사용자 요청에 따라 [AWS CLI](https://github.com/aws/aws-cli)1.46.1과 [공식 Cloudflare Python SDK](https://github.com/cloudflare/cloudflare-python)5.9.0을 PyPI에서 확인해 별도 `.dev-tools/infra-venv`에 설치했다. OpenSSH 클라이언트는 환경에 이미 있다. ChatGPT 플러그인이나 인증 연결을 설치한 것으로 표시하지 않는다.

```sh
make -f tools/Makefile infra-install
make -f tools/Makefile infra-doctor
```

[버전 목록](../tools/infra-requirements.txt)은 제품 런타임과 분리한다. 설치·버전·import는 검증했지만 AWS 조회는 자격증명 없음으로 중단됐고 Cloudflare SDK zone 조회는 인증 설정이 없어 HTTP 요청 전에 중단됐다. 기본 도메인은 pigs0516.com, 대상은 ghostmanual.pigs0516.com이다. 환경의 Cloudflare API 네트워크 허용·인증과 Tailscale VPN/TCP 접속 조건은 별도로 필요하다. 도구 설치만으로 정책을 우회하거나 인증을 생성하지 않는다.
