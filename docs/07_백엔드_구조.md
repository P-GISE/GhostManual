## 검색 경계
검수 완료이며 needsReview=false인 게시 버전만 후보에 포함한다. Owner는 자신의 공간, Reader는 공유 매뉴얼 하나로 제한한다.
자료는 신뢰할 수 없는 입력이다. 문서의 지시를 시스템 명령으로 승격하지 않는다. 외부 URL fetch·웹 검색·도구 실행은 모델에 제공하지 않는다.
후보 최대 20개, AI 문맥 최대 6개, 문맥 최대 12,000자. pg_trgm 실패는 DB 오류로 처리하며 근거 없음으로 위장하지 않는다.
정확한 인용을 검사해도 의미적 정답은 보장되지 않으므로 별도 평가 질문 세트를 사용한다.

## AI 경계와 오류
Responses API strict schema + Zod, refusal/incomplete/timeout/provider error 별도 처리.
unsupported evidence ID·교차 공간 ID·없는 인용은 답변 폐기 후 검색 결과로 전환한다.
store:false, SDK 자동 재시도 0. 명시적 재시도는 새 작업으로 할당량 검사한다.
AI 결과 저장 직전에 revision·권한·만료를 재확인한다. DB 실패 시 성공 응답을 보내지 않는다.

## 인증·로깅·작업
난수 쿠키 및 공유 토큰은 해시 저장, SameSite·Origin·no-store를 적용한다. 상세 접근 정책은 설계안 10절.
일반 로그에는 requestId·상태·시간·모델·토큰 수만 남긴다. 원문·질문·비밀·공유 토큰은 금지한다.
대형 queue나 worker 서비스는 초기 도입하지 않는다. 생성은 제한된 요청 시간 내 처리하고 중복 요청은 DB operation 상태로 구분한다. 종료된 프로세스의 요청을 자동 재실행하지 않는다.
만료 정리는 운영체제 timer에서 하루 한 번 실행하는 별도 명령으로 제안한다. 이 timer는 아직 존재하지 않는다.
