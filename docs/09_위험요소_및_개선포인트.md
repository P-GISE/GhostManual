## 도구 사용 주의

사용자 Codex plugin은 다른 프로젝트에도 보인다. 설치·신뢰 범위는 도구 가이드에서 확인한다. Iron Laws의 검사 대상이 없는 범위는 종료2를 반환할 수 있고 Strix CI 상세 결과는 runner 종료 시 보존되지 않는다. 이는 제품 취약점과 구분해 관리한다.

## 제품 위험 목록·재현·해결 검증

미작성. 새 설계·실제 검사에서 발견한 항목만 근거·우선순위·재현 여부·대응·회귀 검증과 함께 추가한다. 미검증 항목을 해결 완료로 닫지 않는다.

## PC 수집 기획에서 검증할 위험

| ID | 위험 가설 | 검증/대응 제안 |
|---|---|---|
| PC-01 | 화면 알림·다른 앱·계정 정보가 섞일 수 있음 | 합성 비밀값·범위 이탈·정지·잠금으로 업로드 전 필터 검증 |
| PC-02 | 화면/이벤트만으로 목적·판단을 알기 어려움 | 관찰/작성자 보완/미확인 구분, 후임자 재현 실험 |
| PC-03 | OS·앱 권한/보호 화면으로 기록 공백 발생 | 지원 동작 목록·미지원·gap 표시, 성공률 분모에 포함 |
| PC-04 | 반복 캡처·영상·모델 처리로 비용/시간 증가 | 두 수집 경로 비교, 전 시도 비용·지연·상한 기록 |
| PC-05 | 근거 삭제 뒤 파생본에 민감 내용이 남을 수 있음 | 입력/화면/문서/내보내기/캐시의 제외·삭제 정책과 영향 버전 검증 |

이는 PoC 전 위험 가설이며 재현된 제품 결함이 아니다. 상세 실험은 PoC 계획을 따른다.
