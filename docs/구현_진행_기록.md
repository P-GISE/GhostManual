## 이번 실행 근거

- 문서·계획 skill 읽기 및 기존 가이드/TODO 확인.
- npm registry에서 Next16.3.8·React19.3.0·Vitest5.0.3 확인. 실제 의존성 설치는 하지 않았다.
- 로컬 docker version 실패: Linux engine named pipe 없음. CLI 설치와 엔진 실행 상태를 구분했다.
- Tailscale ping은 relay를 통해 pong을 반환했지만 direct connection 미성립으로 종료1. 장비 응답과 직접 연결 성공을 혼동하지 않는다.
- 최초 SSH는 Tailscale 추가 인증으로 timeout. 기존 계정으로 인증 갱신 후 동일 읽기 전용 명령 종료0.
- SSH 결과: Linux, Docker29.5.3, 메모리1906MB/가용805MB, 디스크13GB 남음, 기존 앱 포트3000·3100 사용.
- 서버 명령은 hostname/uname/uptime/free/df/docker version/docker ps/ss 조회만 수행했다. 서버 서비스·DNS·방화벽·파일 변경은 없었다.

## 설계 수정 판단

Ruling: GhostManual 앱 제안 포트3100 → 3200. 3100은 EventOps 사용 중이며 기존 서비스 분리 요구를 따른다. 비용: 배포 문서와 Compose의 포트 일치 검증 필요.
Ruling: 승인 설계의 Node/npm·Next.js·pg를 유지한다. programming skill의 기본 Bun/pnpm·Hono·Drizzle로 변경하지 않는다. 비용: 선택한 조합의 직접 SQL 및 엄격한 타입 검증 책임.
